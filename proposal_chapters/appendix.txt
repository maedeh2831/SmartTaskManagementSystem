پیوست ج: واژه‌نامه تخصصی

| اصطلاح | تعریف |
|---|---|
| Agile | رویکرد توسعه نرم‌افزار مبتنی بر تکرار و تطبیق سریع |

| Backlog | لیست اولویت‌بندی‌شده تمام کارهای مورد نیاز |
| User Story | توصیف کوتاه از قابلیت مورد نیاز کاربر |
| Story Point | واحد اندازه‌گیری پیچیدگی تسک |
| Task | وظیفه اجرایی قابل تحویل |
| Dependency | وابستگی بین دو تسک |
| Workload | بار کاری تخصیص‌یافته به یک عضو |
| Burndown Chart | نمودار پیشرفت اسپرینت |
| Velocity | سرعت تولید تسک در هر اسپرینت |
| SignalR | کتابخانه ارتباط بلادرنگ مایکروسافت |
| WebSocket | پروتکل ارتباط دوطرفه بلادرنگ |
| Entity Framework Core | ORM برای .NET |
| Dependency Injection | الگوی طراحی برای تزریق وابستگی‌ها |
| Unit of Work | الگوی مدیریت تراکنش‌ها |
| Repository | الگوی دسترسی به داده |
| Soft Delete | حذف نرم (غیرفیزیکی) رکوردها |
| Background Service | سرویس پس‌زمینه در ASP.NET Core |
| BFS | جستجوی اول عرض (الگوریتم پیمایش گراف) |
| LLM | مدل زبانی بزرگ (Large Language Model) |
| Prompt | متن ورودی به هوش مصنوعی |
| Push Notification | اعلان فوری در مرورگر |
| CORS | سیاست اشتراک‌گذاری منابع بین‌دامنه |
| RTL | راست‌چین (Right-to-Left) |
