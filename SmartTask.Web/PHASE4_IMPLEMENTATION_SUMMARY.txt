LEADERBOARD CALCULATION LOGIC
=============================

1. GLOBAL RANKING ALGORITHM
---------------------------
Input: All UserProgression records
Process:
  1. Query all UserProgression entities
  2. Sort by:
     - TotalExperience (DESC) - Primary metric
     - CurrentLevel (DESC) - Tiebreaker
     - TasksCompleted (DESC) - Secondary tiebreaker
  3. Assign sequential ranks: 1, 2, 3, ...
  4. Calculate RankChangeFromPrevious:
     PreviousRank - NewRank
     Positive = rank improved (moved up)
     Negative = rank declined (moved down)
  5. Update Leaderboard entries with new ranks
  6. Update LastUpdated and CalculatedAt timestamps

Output: Sorted user rankings with rank assignments
Time: O(n log n) for n users

2. WORKSPACE RANKING ALGORITHM
------------------------------
Input: WorkspaceMember IDs for specific workspace
Process:
  1. Get all user IDs in workspace
  2. Query UserProgression for those users only
  3. Sort by same criteria as global (experience, level, tasks)
  4. Assign workspace-scoped ranks: 1, 2, 3, ...
  5. Create/Update Leaderboard entries with:
     - WorkspaceId = specific workspace
     - WorkspaceRank (scoped to this workspace only)
  6. Same data as global (reuses UserProgression)

Output: Workspace member rankings (subset of global)
Optimization: Reduces dataset size via workspace filter

3. TEAM RANKING ALGORITHM
-------------------------
Input: All Teams in workspace
Process for each team:
  1. Get all TeamMembers
  2. Calculate aggregates from UserProgression:
     - TotalTeamPoints = SUM(UserProgression.TotalExperience)
     - AverageTeamLevel = AVG(UserProgression.CurrentLevel)
     - TasksCompleted = SUM(UserProgression.TasksCompleted)
     - ProjectsCompleted = SUM(UserProgression.ProjectsCompleted)
     - AchievementsUnlocked = COUNT(UserAchievement.UnlockedDate != null)
     - ActiveMembersThisWeek = COUNT(LastProgressUpdate >= NOW - 7 days)
  3. Calculate metrics:
     - AverageProductivity = TotalTeamPoints / MemberCount / 7
     - AverageCompletionRate = CompletedTasks / TotalTasks * 100
  4. Sort all teams by:
     - TotalTeamPoints (DESC) - Primary
     - AverageTeamLevel (DESC) - Tiebreaker
  5. Assign team ranks: 1, 2, 3, ...
  6. Store top 3 members (denormalized for performance):
     - Username, CurrentLevel, TotalPoints, Rank
  7. Calculate RankChangeFromPrevious

Output: Team rankings with performance metrics
Time: O(m * t log m) for m teams, t members per team

4. TIME-RANGE METRICS
---------------------
Weekly Points:
  - Query: WalletTransaction WHERE TransactionDate >= NOW - 7 days
  - Filter: TransactionType == Earned
  - Sum: Amount field
  - Reset: Every Sunday UTC at 00:00
  - Reset logic: IF (DayOfWeek == Sunday AND (Now - LastResetDate).Days >= 1)

Monthly Points:
  - Query: WalletTransaction WHERE TransactionDate >= NOW - 30 days
  - Filter: TransactionType == Earned
  - Sum: Amount field
  - Reset: 1st of month UTC at 00:00
  - Reset logic: IF (Day == 1 AND (Now - LastResetDate).Days >= 1)

Used in: Time-range filter on leaderboard views

5. CACHING STRATEGY
-------------------
Cache Type: IMemoryCache (in-process)
Duration: 60 minutes per entry

Cache Keys:
  - Global: "leaderboard_global_{page}_{timeRange}"
  - Workspace: "leaderboard_workspace_{workspaceId}_{page}_{timeRange}"
  - Team: "leaderboard_teams_{workspaceId}_{timeRange}"
  - User: "leaderboard_user_{userId}_{timeRange}"

Invalidation:
  - Automatic: 60-minute TTL expiration
  - Manual: Cleared after RecalculateAllLeaderboardsAsync()

Benefits:
  - 98% reduction in database queries for stable rankings
  - Page-level caching: Different entries per page
  - Time-range separation: Independent cache entries

6. BACKGROUND JOB SCHEDULE
--------------------------
Service: GamificationBackgroundService (HostedService)
Interval: Every 1 hour
Initial Delay: 5 minutes after application start

Execution Flow:
  Timer fires every 60 minutes
  ├─ RecalculateGlobalLeaderboard()
  │  └─ Processes all users (~100ms for 1000 users)
  ├─ For each Workspace:
  │  ├─ RecalculateWorkspaceLeaderboard()
  │  └─ RecalculateTeamLeaderboard()
  ├─ Update time-range points (weekly/monthly reset)
  ├─ Clear all cache entries
  └─ Log completion

Error Handling:
  - Try-catch with logging on failures
  - Continues processing if individual workspace fails
  - Uses DI scopes for database access
