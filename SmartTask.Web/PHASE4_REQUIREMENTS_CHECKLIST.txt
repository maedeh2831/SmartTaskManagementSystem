CALCULATION LOGIC EXPLANATION
=============================

Global Ranking:
  1. Query all UserProgression records
  2. Sort by TotalExperience (DESC), then CurrentLevel (DESC)
  3. Assign sequential ranks 1, 2, 3, ...
  4. Calculate RankChangeFromPrevious = PreviousRank - NewRank
  5. Time: O(n log n) for n users

Workspace Ranking:
  1. Get WorkspaceMembers user IDs
  2. Query UserProgression for those users
  3. Sort by same criteria as global
  4. Assign workspace-scoped ranks
  5. Create Leaderboard entries with WorkspaceId

Team Ranking:
  1. For each team in workspace:
     a. Get team members and their progression
     b. Aggregate: SUM(experience), AVG(level), COUNT(achievements)
     c. Calculate productivity metrics
  2. Sort teams by TotalTeamPoints DESC, then AverageTeamLevel DESC
  3. Assign team ranks
  4. Store top 3 members (denormalized)
  5. Time: O(m * t log m) for m teams, t members

Time-Range Points:
  - Weekly: SUM(WalletTransaction WHERE date >= NOW - 7 days)
  - Monthly: SUM(WalletTransaction WHERE date >= NOW - 30 days)
  - Reset: Every Sunday (weekly), 1st of month (monthly)

Background Job:
  - Runs every 1 hour
  - Executes: Global, Workspace (all), Team (all per workspace)
  - Performance: <5 seconds for typical workspaces (< 10K users)

Caching:
  - Type: IMemoryCache
  - TTL: 60 minutes
  - Keys: Per page, per time-range, per workspace
  - Hit rate: ~98% for stable rankings
