## 1. معرفی سیستم گیمیفیکیشن

### چرا گیمیفیکیشن؟

در پروژه‌های نرم‌افزاری، یکی از چالش‌های اصلی **حفظ انگیزه تیم** و **شفافیت در عملکرد** است. سیستم گیمیفیکیشن با استفاده از مکانیزم‌های بازی‌وار، این اهداف را محقق می‌کند:

- **انگیزه‌بخشی:** تبدیل فعالیت‌های روزمره به چالش‌های قابل اندازه‌گیری
- **شفافیت:** نمایش واضح عملکرد فردی و تیمی
- **رقابت سالم:** ایجاد فضای رقابتی سازنده بین اعضای تیم
- **بازخورد فوری:** دریافت پاداش و XP بلافاصله پس از تکمیل وظایف

## 2. سیستم امتیازدهی و پیشرفت

### 2.1 Points (امتیاز / سکه)

**Points** واحد پول داخلی سیستم است که با تکمیل فعالیت‌ها به دست می‌آید.

#### منابع کسب Points

| فعالیت | امتیاز پایه | ضریب‌ها |
|--------|------------|---------|
| تکمیل Task | 50-500 | اولویت × پیچیدگی |
| تکمیل Sprint | 300-1000 | تعداد Story × کیفیت |
| تکمیل Project | 500-2000 | اندازه پروژه |
| باز کردن Achievement | متغیر | بر اساس سختی |

#### فرمول محاسبه امتیاز Task

```csharp
basePoints = 100;
priorityMultiplier = priority switch {
    Lowest => 0.5,
    Low => 0.75,
    Medium => 1.0,
    High => 1.5,
    Highest => 2.0
};

complexityBonus = complexity switch {
    Simple => 0,
    Medium => 50,
    Complex => 150
};

finalPoints = (basePoints * priorityMultiplier) + complexityBonus;
```

#### مصرف Points

- **خرید از فروشگاه:** پوسته‌ها، حاشیه‌های آواتار، نشان‌ها
- **قابل انتقال نیست** بین کاربران

### 2.2 Experience (XP) و Level

**XP** نشان‌دهنده تجربه کلی کاربر است و با افزایش، سطح بالاتری کسب می‌شود.

#### رابطه Points و XP

```
XP = Points × 2 × ExperienceMultiplier
```

`ExperienceMultiplier` از **آیتم‌های فروشگاه** به دست می‌آید (مثلاً پوسته طلایی +50% XP).

#### فرمول Level Up

```csharp
requiredXP = baseXP + (level * increment);
// مثال: Level 1→2 نیاز به 1000 XP
//       Level 2→3 نیاز به 1500 XP
```

#### مزایای Level بالا

- **نمایش مهارت** در پروفایل و تابلوی امتیازات
- **باز شدن Achievements** خاص
- **اعتبار بیشتر** در تیم

## 3. دستاوردها (Achievements)

### 3.1 ساختار Achievements

Achievements نشان‌های قابل کسب هستند که با رسیدن به شرایط خاص باز می‌شوند.

```
┌─────────────────────────────────────────┐
│  Achievement: "Sprint Master"          │
├─────────────────────────────────────────┤
│  📋 شرح: 10 اسپرینت را کامل کنید       │
│  ⭐ Rarity: Epic (4/5)                 │
│  🎁 پاداش: 500 Points + 1000 XP       │
│  📊 پیشرفت: 7/10 (70%)                │
│  🔒 وضعیت: قفل                         │
└─────────────────────────────────────────┘
```

### 3.2 دسته‌بندی Achievements

#### بر اساس Category

1. **Task-Based:** وظیفه‌محور (تکمیل اولین Task، 100 Task، ...)
2. **Sprint-Based:** اسپرینت‌محور (تکمیل اسپرینت، Sprint Velocity)
3. **Project-Based:** پروژه‌محور (تکمیل پروژه بزرگ، ...)
4. **Team-Based:** تیمی (کمک به همکاران، رهبری پروژه)
5. **Streak-Based:** توالی (7 روز متوالی فعالیت)

#### بر اساس Rarity

| Rarity | رنگ | ضریب سختی | پاداش |
|--------|-----|----------|-------|
| Common (1) | خاکستری | ساده | 50-100 Points |
| Uncommon (2) | سبز | متوسط | 100-200 Points |
| Rare (3) | آبی | سخت | 200-400 Points |
| Epic (4) | بنفش | خیلی سخت | 400-800 Points |
| Legendary (5) | طلایی | افسانه‌ای | 1000+ Points |

### 3.3 مکانیزم Unlock

```csharp
// بررسی شرایط هر Achievement
public async Task OnTaskCompletedAsync(int taskId, int userId)
{
    var progression = await GetUserProgressionAsync(userId);
    
    // چک Achievement "First Task"
    if (progression.TasksCompleted == 1) {
        await UnlockAchievementAsync(userId, "first-task");
        await AwardRewardAsync(userId, 50, 100); // 50 points, 100 XP
    }
    
    // چک Achievement "Centurion" (100 tasks)
    if (progression.TasksCompleted == 100) {
        await UnlockAchievementAsync(userId, "centurion");
        await AwardRewardAsync(userId, 500, 1000);
    }
}
```

## 4. فروشگاه و آیتم‌های تزئینی

### 4.1 انواع آیتم‌ها

#### Theme (پوسته رنگی)

**تأثیر:** تغییر رنگ‌بندی کل رابط کاربری  
**نحوه اعمال:** `data-shop-theme="theme-slug"` روی `<html>`

```html
<!-- تم پیش‌فرض -->
<html data-shop-theme="">

<!-- تم Cyber Purple -->
<html data-shop-theme="cyber-purple">
```

**مثال آیتم:**
```json
{
  "id": 101,
  "name": "Cyber Purple",
  "category": "Theme",
  "price": 500,
  "rarity": 3,
  "perkType": "ExperienceMultiplier",
  "perkValue": 1.25,  // +25% XP
  "themeSlug": "cyber-purple"
}
```

#### Avatar Border (حاشیه آواتار)

**تأثیر:** حاشیه رنگی دور تصویر پروفایل  
**کاربرد:** نمایش وضعیت در تابلوی امتیازات و هدر

```css
.user-avatar.has-equipped-border {
  border: 3px solid var(--equipped-border-color);
  box-shadow: 0 0 12px var(--equipped-border-color);
}

.border-legendary {
  animation: rainbow-pulse 2s infinite;
}
```

#### Badge (نشان)

**تأثیر:** آیکون کوچک روی گوشه آواتار  
**کاربرد:** نمایش دستاوردهای خاص

```html
<div class="user-avatar">
  <img src="avatar.jpg">
  <span class="user-avatar-badge" title="Top Performer">👑</span>
</div>
```

### 4.2 Perks (مزایا)

برخی آیتم‌ها **مزیت عملیاتی** دارند:

| Perk Type | توضیح | مثال |
|-----------|-------|------|
| ExperienceMultiplier | ضریب XP | تم طلایی: +50% XP |
| PointsBonus | امتیاز ثابت روزانه | حاشیه افسانه‌ای: +100 Points/day |
| StreakProtection | محافظ Streak | نشان ویژه: 1 روز بخشودگی |

### 4.3 مکانیزم خرید و Equip

#### خرید

```
POST /api/gamification/marketplace/purchase

{
  "itemId": 101
}

→ Response:
{
  "success": true,
  "newBalance": 1500,
  "inventoryId": 42
}
```

کاربر باید موجودی کافی داشته باشد. پس از خرید، آیتم به **Inventory** اضافه می‌شود.

#### فعال‌سازی (Equip)

```
POST /api/gamification/inventory/42/equip

→ Response:
{
  "message": "Item equipped successfully",
  "cosmetics": {
    "themeSlug": "cyber-purple",
    "avatarBorderColor": null,
    "avatarBorderName": null,
    "badgeIcon": null,
    "experienceMultiplier": 1.25
  }
}
```

**نکته مهم:** پاسخ شامل `cosmetics` است تا صفحه **بدون رفرش** به‌روزرسانی شود:

```javascript
fetch('/api/gamification/inventory/42/equip', { method: 'POST' })
  .then(r => r.json())
  .then(data => {
    applyCosmetics(data.cosmetics); // اعمال فوری
    showToast('آیتم فعال شد');
  });
```

### 4.4 محدودیت Slot

- **یک Theme** فعال
- **یک Avatar Border** فعال
- **یک Badge** فعال

Equip کردن آیتم جدید، آیتم قبلی را Unequip می‌کند.

## 6. تحلیل بهره‌وری

### 6.1 Productivity Metrics

**مسیر:** `/ProductivityMVC`  
**API:** `GET /api/productivity/metrics/{userId}`

#### شاخص‌های اندازه‌گیری‌شده

| Metric | توضیح | واحد |
|--------|-------|------|
| **Completion Rate** | نسبت تکمیل به شروع | درصد |
| **Average Velocity** | سرعت تکمیل Task | Task/Week |
| **On-Time Delivery** | تکمیل به‌موقع | درصد |
| **Quality Score** | کیفیت کار (بدون بازگشت) | نمره 1-100 |
| **Streak (روزهای متوالی)** | تعداد روزهای فعالیت پیاپی | روز |

#### نمودارها

- **خط زمانی Points** (30 روز گذشته)
- **ستونی Tasks Completed** (هفتگی)
- **دایره‌ای Task Status** (Done, In Progress, Todo)
- **Heatmap فعالیت** (تقویم)

### 6.2 Streak System

**Streak** تعداد روزهای متوالی فعالیت است که انگیزه مداومت را افزایش می‌دهد.

```
┌────────────────────────────────────┐
│  🔥 Current Streak: 12 days       │
│  🏆 Longest Streak: 45 days       │
│                                    │
│  روزهای اخیر:                      │
│  ✅ ✅ ✅ ✅ ✅ ✅ ✅               │
│  امروز  دیروز  2 روز پیش  ...    │
└────────────────────────────────────┘
```

**محاسبه:**
- هر روز حداقل **1 Task** تکمیل شود → Streak ادامه دارد
- یک روز بدون فعالیت → Streak از صفر شروع می‌شود
- **Streak Protection Perk:** یک روز بخشودگی

### 7.1 Critical Path Analysis

**مسیر:** `/SimulationMVC?projectId=X`

```
Task A ──→ Task B ──→ Task C ──→ Task D
  (5d)      (3d)      (2d)      (4d)
           ↑ Critical Path ↑
           
Task E ──→ Task F
  (2d)      (1d)

```

## 8. سیستم ضد سوء‌استفاده

### 8.1 چرا نیاز به Anti-Abuse بود؟

قبل از پیاده‌سازی محافظ‌ها، اکسپلویت‌های زیر وجود داشت:

#### اکسپلویت 1: Reward Farming (Toggle Exploit)

```
1. Task را Done کنید → +150 Points ✅
2. Task را برگردانید به InProgress
3. دوباره Done کنید → +150 Points ✅ (دوباره!)
4. تکرار بی‌نهایت...
```

#### اکسپلویت 2: Fake Task Creation

```
1. Task با عنوان "a" بسازید
2. بلافاصله Done کنید → +100 Points
3. در 1 دقیقه 10 Task جعلی → +1000 Points
```

#### اکسپلویت 3: Rate Abuse

```
با اسکریپت خودکار در 1 ساعت 100 Task Done کنید
```

### 8.2 راه‌حل: RewardEligibilityService

قبل از هر پاداش، **7 قانون** بررسی می‌شود:

#### قانون 1: Idempotency (یک پاداش در کل عمر Task)

```csharp
// بررسی دفتر تراکنش‌ها (WalletTransaction)
var alreadyRewarded = await _context.WalletTransactions
    .AnyAsync(t => t.RelatedTaskId == taskId 
                && t.TransactionType == TransactionType.Earned
                && t.UserWallet.UserId == userId);

if (alreadyRewarded)
    return RewardEligibility.Deny("برای این تسک قبلاً پاداش داده شده");
```

این قانون **اکسپلویت Toggle** را کاملاً سد می‌کند.

#### قانون 2: وضعیت واقعی

```csharp
if (task.Status != TaskStatusType.Done)
    return Deny("تسک در وضعیت تکمیل‌شده نیست");
```

#### قانون 3: Assignment

```csharp
var isAssigned = task.Assignments.Any(a => a.ApplicationUserId == userId);
if (!isAssigned)
    return Deny("کاربر به این تسک تخصیص ندارد");
```

#### قانون 4: عنوان معتبر

```csharp
const int MinimumTitleLength = 3;
if (task.Title.Trim().Length < MinimumTitleLength)
    return Deny("عنوان تسک معتبر نیست");
```

#### قانون 5: عمر Task

```csharp
var lifetime = task.CompletedDate - task.CreatedDate;
if (lifetime < TimeSpan.FromSeconds(30))
    return Deny("تسک بلافاصله پس از ایجاد تکمیل شده");
```

جلوی **Fake Task** را می‌گیرد.

#### قانون 6: سقف نرخ (Rate Limit)

```csharp
const int MaxRewardsPerHour = 20;
const int MaxRewardsPerDay = 60;

var rewardsLastHour = await CountRecentRewardsAsync(userId, now.AddHours(-1));
if (rewardsLastHour >= MaxRewardsPerHour)
    return Deny("سقف پاداش ساعتی پر شده");
```

#### قانون 7: تعلیق

```csharp
if (await _abuseEngine.IsUserSuspendedAsync(userId))
```

### 8.3 تست اکسپلویت

تست واقعی که اکسپلویت را امتحان می‌کند:

```csharp
[Fact]
public async Task RepeatedCompletion_DoesNotAwardPointsTwice()
{
    // Setup: یک Task تکمیل‌شده
    var (userId, task) = SeedCompletedTask(context);
    
    // اولین بار: باید پاداش بدهد
    await coordinator.HandleTaskCompletedAsync(task.Id, ...);
    var balanceAfterFirst = GetBalance(userId);
    Assert.True(balanceAfterFirst > 0);
    
    // اکسپلویت: برگرداندن به InProgress و تکمیل دوباره
    task.Status = TaskStatusType.InProgress;
    await context.SaveChangesAsync();
    
    task.Status = TaskStatusType.Done;
    await context.SaveChangesAsync();
    
    // دومین بار: نباید پاداش بدهد
    await coordinator.HandleTaskCompletedAsync(task.Id, ...);
    var balanceAfterSecond = GetBalance(userId);
    
    Assert.Equal(balanceAfterFirst, balanceAfterSecond); // ✅ بدون تغییر
}
```

### 8.4 Abuse Detection Engine

موتور **تشخیص خودکار** سوء‌استفاده با اسکن دوره‌ای:

```csharp
public async Task ScanUserActivityAsync(int userId)
{
    var rules = new[] {
        new AbuseRule {
            Name = "Suspicious Task Count",
            Check = () => CountTasksInWindow(userId, hours: 1) > 15
        },
        new AbuseRule {
            Name = "Rapid Self-Assignment",
            Check = () => CountSelfAssignedCompleted(userId, minutes: 5) > 3
        }
    };
    
    foreach (var rule in rules) {
        if (await rule.Check()) {
            await CreateAbuseReportAsync(userId, rule.Name, AbuseReportStatus.Pending);
        }
    }
}
```

گزارش‌های Abuse در پنل ادمین قابل بررسی است و می‌توان کاربر را تعلیق کرد.

### 9.4 Client-Side Instant Apply

```javascript
// کاربر روی Equip کلیک می‌کند
function toggleEquip(itemId) {
    fetch(`/api/gamification/inventory/${itemId}/equip`, { method: 'POST' })
        .then(r => r.json())
        .then(data => {
            // بدون رفرش صفحه:

            // ✅ تم فوراً عوض می‌شود
            // ✅ حاشیه آواتار به‌روز می‌شود
            // ✅ نشان ظاهر می‌شود
        });
}

function applyCosmetics(cosmetics) {
    if (cosmetics.themeSlug) {
        document.documentElement.setAttribute('data-shop-theme', cosmetics.themeSlug);
    }
    
    const avatar = document.querySelector('.user-avatar');
    if (cosmetics.avatarBorderColor) {
        avatar.style.setProperty('--equipped-border-color', cosmetics.avatarBorderColor);
        avatar.classList.add('has-equipped-border');
    }
    
    if (cosmetics.badgeIcon) {
        const badge = document.createElement('span');
        badge.className = 'user-avatar-badge';
        badge.textContent = cosmetics.badgeIcon;
        avatar.appendChild(badge);
    }
}
```

### 10.2 باگ‌های اصلاح‌شده
